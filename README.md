## Proyectos destacados

### [SMR Hub](https://github.com/NormalGuy749/SMR_Hub)

> Una app web hecha por un estudiante de SMR para estudiantes de SMR.

Plataforma para estudiar todo el ciclo de grado medio de **Sistemas Microinformáticos y Redes**. Reúne herramientas prácticas (calculadoras de IPs, conversores de numeración), zonas de estudio y **quizzes a medida**, con más funcionalidades en camino.

**Por qué destaca técnicamente**

- **Pensado desde los datos:** usa SQL y Supabase como base del proyecto, en línea con mi enfoque de aprender arquitectura centrada en bases de datos, en vez de añadir la persistencia al final.
- **Estructura separada por responsabilidades:** interfaz (`css/`, `js/`), backend y datos (`supabase/`) y recursos de marca (`assets/brand/`) viven en carpetas distintas, lo que facilita ampliarlo sin romper lo existente.
- **Entorno reproducible:** Docker permite levantar el proyecto igual en cualquier máquina.
- **JavaScript con tipado:** TypeScript en el stack para detectar errores antes de ejecutar.
- **Producto con usuario real:** nace de una necesidad concreta (estudiar SMR), así que cada funcionalidad se decide pensando en quién la va a usar.
